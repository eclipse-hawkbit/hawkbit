# hawkbit-ui

Vaadin Flow UI (`HawkbitUiApp`, port `${PORT:8088}`). It talks to the Mgmt REST API at `hawkbit.server.mgmtUrl` through Feign clients (`hawkbit-sdk-commons` + `hawkbit-mgmt-api`). It has no direct DB access.

## Commands
- Build: `mvn -pl hawkbit-ui -am install -DskipTests` (`vaadin-maven-plugin` prepare/build-frontend, production mode). Needs Node; Vaadin downloads it if missing.
- Run: `java -jar hawkbit-ui/target/hawkbit-ui.jar`. The `-0-SNAPSHOT.jar` is the plain, non-boot jar.

## Rules
- Generated by Vaadin and git-ignored (`hawkbit-ui/.gitignore`), so never edit or commit them: `node_modules`, `package*.json`, `tsconfig.json`, `types.d.ts`, `vite.*.ts`, `src/main/bundles`, `src/main/frontend/*`.
- Only `src/main/frontend/themes/` is source (styles live in `themes/hawkbit/`).
- New data needs go through the Mgmt API (`hawkbit-mgmt-api` interfaces). Don't add repository dependencies.
